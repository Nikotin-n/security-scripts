# 🛡️ Security Scripts & Automation

This repository contains a collection of custom scripts and utilities created to automate various tasks in cybersecurity.

The main goal of this project is to streamline routine processes, increase efficiency during security research, and speed up practical tasks.

---

## 📌 Main Focus

The scripts in this repository are developed to cover the following areas:

* **OSINT (Open Source Intelligence):** Automation of open-source data collection and initial analysis.
* **Web Security:** Tools for checking web resource configurations, analyzing HTTP headers, and identifying basic vulnerabilities.
* **CTF & Crypto Utils:** Helper utilities for fast data decoding, parsing, and solving CTF challenges.
* **General Automation:** Lightweight scripts for text processing, file operations, and network requests.

---

## 🛠️ Tech Stack

Most tools are written in **Python** using standard and popular third-party libraries, as well as **Bash** scripts for Linux environments.
